Inside the runs

Watch an AI scientist run its experiments, then watch the checker.

Each run is replayed in three beats. 1 Experiments: particles move under a hidden law and the lab returns noisy snapshots, which is all the agent sees. 2 Claim: the agent states a verdict and its measured numbers. 3 Checker: the true paths are revealed, the numbers are checked against the truth, and each reward rule pays out.
